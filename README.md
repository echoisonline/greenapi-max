# Чат MAX через GREEN-API

Веб-клиент на React и TypeScript для переписки в MAX через GREEN-API (instance API v3). Интерфейс повторяет тёмную тему web.max.ru.

## Что реализовано

- Подключение по `apiUrl`, `idInstance` и `apiTokenInstance` с проверкой состояния инстанса (`getStateInstance`). Данные можно запомнить на устройстве.
- Выбор собеседника по номеру телефона (РФ и РБ, chatId находится через `checkAccount`) или по MAX chatId.
- Отправка текстовых сообщений (`sendMessage`) со статусом отправки и повтором при ошибке.
- Получение входящих без перезагрузки страницы: `receiveNotification` → обработка → `deleteNotification`, с переподключением при сбоях сети.

Поддерживается один личный чат и только текст. История до открытия чата не загружается.

## Подготовка инстанса

Нужен инстанс MAX в [личном кабинете GREEN-API](https://console.green-api.com/), авторизованный в мессенджере. В настройках инстанса `webhookUrl` должен быть пустым, а `incomingWebhook` — `yes`. Параметры подключения берутся там же. Подробнее — в [документации](https://green-api.com/v3/docs/before-start/).

## Установка и запуск

Нужен Node.js 24.

```bash
npm ci
npm run dev
```

Приложение откроется на http://localhost:5173.

Сборка и просмотр production-версии:

```bash
npm run build
npm run preview
```

Проверки:

```bash
npm test          # тесты
npm run lint      # линтер
npm run typecheck # типы
```

## Важно

Браузер обращается к GREEN-API напрямую, поэтому токен виден в адресах запросов. Это демо: используйте инстанс, токен которого не жалко сменить.
